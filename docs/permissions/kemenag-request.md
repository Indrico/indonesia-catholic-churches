Yth. Pengelola Data Ditjen Bimas Katolik Kementerian Agama RI,

Kami menyiapkan direktori terbuka tempat ibadah Katolik Indonesia di https://github.com/Indrico/indonesia-catholic-churches. Kami memeriksa halaman https://bimaskatolik.kemenag.go.id/index.php/dataset/5 dan menemukan bahwa tautan unduh saat ini menyediakan workbook XLSX berisi jumlah tempat ibadah menurut 34 provinsi, bukan daftar setiap tempat ibadah.

Mohon penjelasan mengenai:

1. Lisensi dan ketentuan penggunaan ulang, normalisasi, serta publikasi ulang data tersebut dalam JSON/CSV di GitHub publik dan kelak API baca-saja, termasuk penggunaan komersial oleh pihak lain.
2. Teks atribusi, identitas penerbit, tahun acuan, tanggal pembaruan, serta batasan cakupan administratif yang harus dicantumkan.
3. Ketersediaan ekspor atau API resmi berisi nama tempat ibadah, jenis, alamat, wilayah administratif, keuskupan, dan koordinat jika tersedia, dengan kontak institusional saja.
4. Identitas stabil tempat ibadah, pemisahan paroki sebagai organisasi dari gedung gerejanya, dan prosedur koreksi data.
5. Kolom atau sumber pihak ketiga yang memiliki syarat berbeda, batas laju akses, serta kewenangan pemberian izin publikasi ulang.
6. Persetujuan untuk mempublikasikan ringkasan izin yang telah disunting tanpa data pribadi sebagai bukti izin.
