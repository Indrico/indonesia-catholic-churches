Yth. Pengelola Paroki.org,

Kami sedang menyiapkan proyek komunitas Open Catholic Church Directory of Indonesia, dengan repositori publik https://github.com/Indrico/indonesia-catholic-churches. Tujuannya menyediakan data tempat ibadah Katolik di Indonesia yang konsisten, memiliki atribusi dan asal-usul setiap nilai, serta dapat digunakan oleh pengembang melalui JSON/CSV dan kelak API baca-saja.

Kami telah memeriksa ketentuan situs, robots.txt, sitemap, dan tiga profil sebagai sampel struktur. Kami belum menjalankan ekstraksi massal maupun menerbitkan ulang rekaman profil.

Mohon konfirmasi tertulis mengenai hal-hal berikut:

1. Apakah tersedia ekspor resmi atau API yang dianjurkan, sehingga kami tidak perlu merayapi setiap profil?
2. Apakah pengambilan otomatis secara massal, normalisasi, penyimpanan cache, serta pembaruan berkala diizinkan? Jika ya, berapa batas laju, jam akses, dan identitas User-Agent yang dikehendaki?
3. Apakah data hasil normalisasi boleh diterbitkan ulang sebagai JSON dan CSV dalam repositori GitHub publik, termasuk file per provinsi/keuskupan, riwayat Git, dan layanan API baca-saja pada masa mendatang?
4. Apakah pengguna turunannya boleh menggunakan data tersebut untuk keperluan komersial maupun non-komersial? Proyek ini memerlukan izin penggunaan ulang terbuka bagi penggunanya, bukan hanya izin internal proyek.
5. Lisensi data apa yang harus dicantumkan, dan bagaimana teks atribusi serta tautan sumber yang tepat pada tingkat rekaman dan dokumentasi? Mohon identifikasi lisensi yang Anda berwenang berikan; kami tidak akan menetapkannya secara sepihak.
6. Apakah ada sumber pihak ketiga atau kolom tertentu yang hak publikasi ulangnya tidak tercakup, dan apakah izin ini mencakup hak kompilasi serta kewajiban dari sumber-sumber tersebut?
7. Bagaimana prosedur koreksi, pencabutan izin, perubahan ketentuan, dan penanganan salinan lama dalam riwayat Git?
8. Apakah kami boleh mempublikasikan ringkasan izin yang telah disunting agar tidak memuat data pribadi sebagai bukti izin?
